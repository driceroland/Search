# Search Split View

The terms Search uses for showing two open tabs at once.

## Language

**Split view**:
Two open tabs shown at the same time in separate panes of one Search window. The tabs stay separate in the tab row or sidebar.

**Split pair**:
Two separate tabs in one Space linked so either can return to their split view. The link stays while another tab fills the window.

**Pending split**:
A temporary layout with one tab and an empty pane while a person chooses the second tab.
